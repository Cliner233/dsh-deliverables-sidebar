# 对话交付物

右侧栏新增「对话交付物」入口；不在对话标题旁显示快捷按钮。

- 默认最新在前，可切换最早在前。排序取同一路径最后一次对话产出时间，非磁盘修改时间。
- 汇总明确交付、成功写入/修改，以及助手回复的本地 Markdown 文件链接。
- 同一路径合并，不同目录的同名文件分别保留。重复同名时显示完整路径。
- 支持文件名/路径/描述搜索、来源筛选，点击通过现有 DSH 文件预览打开。
- 使用 Host 会话投影读取完整已记录历史，非仅已加载的聊天窗口。
- 不扫描磁盘、不汇总子会话，不将用户上传附件当成交付物。
- 链接可能已失效，文件内容取打开时的当前内容，不保存历史快照。
- 仅命令行创建且没有交付或链接的文件无法识别；无文件系统记录时不猜测。
- 排序偏好保留到当前页面插件生命周期结束。无联网、无删除、无自动打开文件。


## 安装

1. 点击本仓库的 Code → Download ZIP，解压到固定目录。
2. 在解压后的插件目录打开终端，执行：

   ```powershell
   npm install --ignore-scripts
   ```

3. 在 DSH 中打开「插件管理 → 添加插件 → 本地目录」，选择该插件目录。
4. 启用插件，必要时刷新 DSH 页面。

请勿在安装后移动或删除插件目录，本地安装会链接到该目录。

开发时适配版本：DSH 0.2.2-rc.5，其他版本兼容性尚未验证。
